# ImageToPDF

I have made a simple to use app built with **Python** & **Tkinter** that can convert supported one or more images to a pdf file.

# Features

1. You can select multiple PNG, JPG and JPEG images
2. Combine all those images to PDF
3. You can choose where you can save the PDF
4. The images get centered to fit the page
5. Clean UI
6. Tells you if you get an error
7. Let's you know if the conversion was successfull
8. Can't convert until some image is used
9. Made into a Executable file

# Installation

You don't have to do much to get this app running on your desktop. You can simply head over to my release section and then download the exe file. After it is complete downloading just double click and start using the app.

# Built With

1. Python
2. Tkinter
